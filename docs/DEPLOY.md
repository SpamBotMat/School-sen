# Запуск с нуля

Всё бесплатно: **Render Free** (сервер) + **Neon Free** (база) + **cron-job.org** (будильник).
Займёт ~40 минут. Telegram и onrender.com у нас открываются только через VPN — держи его включённым.

Что понадобится: аккаунт GitHub, Telegram, компьютер с Python 3 (только чтобы сгенерировать ключи).

---

## 1. Бот в @BotFather

1. `/newbot` → имя: `School Sensor` → username, например `sensor_trsosh_bot` (должен кончаться на `bot`).
2. BotFather пришлёт **токен** вида `123456789:AA…` — это `BOT_TOKEN`. Никому не показывай.
3. `/setuserpic` → выбери бота → отправь картинку `assets/brand/logo-640.png` (как фото).
4. `/setdescription` (видно до нажатия «Старт»), например:
   `Слежу за дневником NetSchool: новые оценки, ДЗ, сводки утром и вечером, калькулятор четверти. Неофициальный помощник.`
5. `/setabouttext` (в профиле бота): `Помощник для дневника NetSchool. Неофициальный.`

Команды и кнопку «Дневник» бот выставит **сам** при запуске. `/setdomain` и `/newapp` не нужны.

6. Узнай свой Telegram ID: напиши [@userinfobot](https://t.me/userinfobot) → число `Id` — это `ADMIN_IDS`
   (несколько админов — через запятую).

## 2. База в Neon

1. [neon.tech](https://neon.tech) → Sign up → **Create project**: имя `school-sensor`,
   регион **AWS Europe Central 1 (Frankfurt)** — рядом с сервером Render.
2. **Connect** → выключи **Connection pooling** → скопируй строку подключения:
   `postgresql://neondb_owner:…@ep-…eu-central-1.aws.neon.tech/neondb?sslmode=require` — это `DATABASE_URL`.
   (Адрес **без** `-pooler`. С пулером тоже заработает, но прямое подключение проще.)
3. Таблицы приложение создаст само при первом запуске.

## 3. Ключи

```bash
python3 tools/genkey.py
```

Выведет `CREDENTIALS_KEY=…` и `TICK_KEY=…`.

- `CREDENTIALS_KEY` шифрует сохранённые входы. **Сохрани в менеджер паролей и никогда не меняй:**
  потерял/сменил — всем ученикам придётся подключаться заново.
- `TICK_KEY` — секрет для будильника. Render может сгенерировать его сам (см. ниже) — тогда этот не нужен.

## 4. Приватный репозиторий

1. GitHub → **New repository** → имя `school-sensor` → **Private** → без README.
2. Чтобы в истории коммитов не было твоего имени и почты:
   GitHub → Settings → Emails → включи **Keep my email addresses private** — там написан адрес
   вида `12345678+login@users.noreply.github.com`.
3. В папке проекта:

```bash
git init -b main
git config user.name "School Sensor"
git config user.email "12345678+login@users.noreply.github.com"
git add .
git status            # проверь: нет .env, dumps/, tests/netschool/fixtures/
git commit -m "School Sensor 1.0"
git remote add origin https://github.com/<логин>/school-sensor.git
git push -u origin main
```

## 5. Render

1. [render.com](https://render.com) → войти через GitHub → **New → Blueprint** → выбери репозиторий.
   Render прочитает `render.yaml` (Docker, Free, Frankfurt, проверка `/health`).
2. Заполни секреты, которые он спросит:

| Переменная | Что вписать |
|---|---|
| `BOT_TOKEN` | токен из BotFather |
| `DATABASE_URL` | строка из Neon |
| `CREDENTIALS_KEY` | из `tools/genkey.py` |
| `ADMIN_IDS` | твой Telegram ID |

   `TICK_KEY` Render сгенерирует сам — посмотреть: сервис → **Environment**.
3. **Apply**. Сборка 3–6 минут, первый старт на слабом CPU — до минуты.
4. Открой `https://<сервис>.onrender.com/health` → должно быть `{"ok":true,"version":"1.0.0"}`.
5. В **Logs** при старте видно `School Sensor 1.0.0 запущен` (при первом старте ещё и `Вебхук установлен`).
   Если что-то не так с настройками — строки `Настройки: …`.

`PUBLIC_URL` задавать не нужно — Render сам передаёт адрес сервиса. Свой домен подключишь — впиши его в `PUBLIC_URL`.

Остальные переменные (можно не трогать):

| Переменная | По умолчанию | Зачем |
|---|---|---|
| `NETSCHOOL_URL` | `http://school.trsosh.edu.tm` | адрес дневника |
| `SCHOOL_NAME`, `CITY_NAME` | СТРСОШ им. А.С. Пушкина, Ашхабад | подписи |
| `WEATHER_LAT`, `WEATHER_LON` | 37.95, 58.38 | точка для погоды |
| `DB_FLUSH_SECONDS` | 900 (в render.yaml) | как часто писать изменения в базу; реже — меньше «часов» Neon |
| `LOG_LEVEL` | INFO | DEBUG — подробнее |

## 6. Будильник на cron-job.org

Бесплатный Render засыпает через 15 минут без запросов — тогда не уйдут утренние сводки.

1. [cron-job.org](https://cron-job.org) → **Create cronjob**.
2. URL: `https://<сервис>.onrender.com/tick?key=<TICK_KEY>`
3. Расписание: **каждые 10 минут**. Сохрани.
4. Через пару минут в истории задания должно быть `200 OK`.

`/tick` заодно перезапускает планировщик, если он вдруг упал.

> Лимит Render Free — 750 часов в месяц на аккаунт: одному сервису 24/7 хватает (744 ч),
> но второй бесплатный сервис постоянно не держи. Хочешь запас — в cron-job.org поставь будильник
> только с 06:00 до 23:50 (часовой пояс Asia/Ashgabat): ночью опроса всё равно нет,
> а если кто-то напишет боту — Render проснётся сам (ответ придёт через ~минуту).

## 7. Первый запуск

1. Напиши боту `/start` (сначала **сам**, иначе бот не сможет прислать тебе код) → «Подключаем?» →
   логин → пароль. Сообщение с паролем исчезнет, через несколько секунд придёт «Вход работает ✅».
2. Нажми кнопку **«Дневник»** слева от поля ввода — откроется Mini App.
3. `/admin` → бот пришлёт код и кнопку **«Войти в админку»** → откроется панель в браузере.
   На «Обзоре» не должно быть красных предупреждений.

Если вход пишет, что **сайт школы не отвечает**, а из дома сайт открывается — значит, серверу Render
(Франкфурт) сайт недоступен. Это главный непроверенный риск, см. [DECISIONS.md](DECISIONS.md#риски-и-что-не-проверено).

## 8. Пилот (рекомендую)

1. Админка → **Настройки** → «Регистрация» → **По приглашениям** → Сохранить.
2. **Приглашения** → «Для кого: пилот», 10 человек, 14 дней → Создать → отправь ссылку
   `t.me/<бот>?start=inv_…` 5–10 одноклассникам.
3. Неделю смотри: **Обзор** (опросы, ошибки, память), **Журнал** (жёлтые/красные события), **Обращения**.
4. Всё спокойно → «Регистрация» → **Открыта всем**.

## 9. Обновления

`git push` → Render сам пересоберёт и перезапустит (3–6 минут). Перед остановкой приложение
записывает всё в базу; Telegram придержит сообщения и доставит после старта.
После перезапуска в админку нужно войти заново (`/admin`).

## 10. Если что-то не так

| Симптом | Что проверить |
|---|---|
| `/health` не открывается | Render → Logs: ошибка сборки или старта; сервис не в статусе *Suspended* |
| Бот молчит | Logs: нет ли `Telegram: настройка не удалась`; верный ли `BOT_TOKEN`; сервис запущен |
| Кнопка «Дневник» не появилась | перезапусти чат с ботом; в Logs нет `Не удалось настроить команды/кнопку` |
| У всех «сайт школы не отвечает» | сайт лежит или поставил паузу предохранитель — бот пишет админу; проверь сайт сам |
| В админке память > 450 МБ | перезапусти сервис (Manual Deploy → Restart service); повторяется — подними «Минут между опросами» или перейди на Starter |
| Neon: закончились часы | база спит до нового месяца — данные копятся в памяти; подними `DB_FLUSH_SECONDS` до 1200 |
| Mini App пустой/белый | у ученика VPN только для Telegram (прокси) — Mini App грузится с onrender.com, нужен VPN на всё устройство; бот в чате работает и так |

Локальная проверка настроек: `python -m app check`.
